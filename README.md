## Overview

DescargarBot is an **on-demand scraper** built for its community. It receives requests, runs the extraction and returns results through three entry points:

- **Web**
- **Telegram bot**
- **Discord server**

> **Community:** 15,000+ active users  
> **Volume:** 3,000+ requests per day  
> **Model:** on-demand, multi-platform  
> **Status:** active and running for over 4 years
